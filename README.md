# 🎬 Movie App

A responsive **Movie Search & Browsing Web Application** built using **HTML5, CSS3, and Vanilla JavaScript**, powered by the **OMDb API**.

The app displays **recent movies on initial load (year-based)** and allows users to **search movies by title**, browse results with **pagination**, and interact with a clean, modern UI.


---

## 🚀 Live Demo
🔗 https://gsumithub.github.io/Movie-App/

---

## ✨ Features

- 🔍 Search movies by title using OMDb API  
- 🎞️ Recent movies displayed on first load (filtered by current year)  
- 📄 Pagination with Previous / Next navigation  
- 🎨 Dark-themed UI with smooth hover transitions  
- 📱 Fully responsive design (desktop, tablet, mobile)  
- ⚡ Built using **pure JavaScript** (no frameworks)

---

## 🛠️ Tech Stack

- **HTML5** — semantic and accessible structure  
- **CSS3** — Grid layout, transitions, responsive styling  
- **JavaScript (ES6)** — API fetching, DOM manipulation, pagination logic  
- **OMDb API** — movie data source  

---

## 📸 Preview

> Movie posters, titles, and release years are dynamically rendered from the API with graceful fallbacks for missing images.

## 🧠 What I Learned

- Managing UI state (search, pagination, page count)

---

## 📌 Note

OMDb does not provide a dedicated “latest movies” endpoint, so recent movies are displayed using a **year-based filtering approach**, which is suitable for learning and portfolio projects.
